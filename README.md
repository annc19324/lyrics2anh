# Lyrics2Anh - Tạo ảnh Lyrics Tiktok

Ứng dụng web đơn giản giúp tạo ảnh lyrics bài hát phong cách Tiktok/Instagram với giao diện đẹp mắt và nhiều tùy chỉnh.

## Tính năng chính

*   **Tạo ảnh Lyrics tự động**: Nhập tên bài hát, ca sĩ, và lời bài hát để tạo ngay 2 ảnh (Bìa + Lyrics).
*   **Tùy chỉnh Giao diện (Style)**:
    *   Hỗ trợ nhiều mẫu (Split Art, Centered Stack, Full Screen).
    *   Thay đổi phông chữ (Patrick Hand, Dancing Script, Inter, ...).
    *   Chỉnh màu sắc, kích thước chữ, độ mờ nền.
*   **Mặt nạ ảnh (Creative Masks)**:
    *   Cắt ảnh theo nhiều hình dạng độc đáo: Tròn, Bo góc, Vòm.
    *   **Mới**: Gai góc (Grunge), Giọt nước (Blob), Nét cọ (Brush), Ngôi sao (Star).
*   **Lưu trữ tự động**: Mọi thay đổi của bạn (vị trí, nội dung, màu sắc) được lưu tự động vào trình duyệt. Reload không mất dữ liệu.
*   **Upload ảnh**: Tải lên ảnh nền và ảnh bìa (Art) từ máy tính của bạn.
*   **Download**: Tải xuống trọn bộ 2 ảnh với chất lượng cao.

## Công nghệ sử dụng

*   **HTML5 / CSS3**: Giao diện hiện đại, responsive.
*   **JavaScript (Vanilla)**: Xử lý logic canvas, mask, và state management.
*   **LocalStorage**: Lưu trữ trạng thái người dùng.
*   **Google Fonts**: Font chữ đa dạng.
*   **Font Awesome**: Icon giao diện.

## Cách chạy dự án

1.  Clone repository:
    ```bash
    git clone https://github.com/annc19324/lyrics2anh.git
    ```
2.  Mở thư mục dự án và chạy file `index.html` trực tiếp trên trình duyệt.
    *   *Lưu ý*: Một số tính năng (như load ảnh file://) có thể bị hạn chế do bảo mật trình duyệt.
3.  (Khuyến nghị) Sử dụng Live Server hoặc `npx serve .` để có trải nghiệm tốt nhất.
    ```bash
    npx serve .
    ```
